# Code of Conduct

## Our standard

Vibe Roaster welcomes contributors with different backgrounds and experience
levels. Participate with respect, technical honesty, and care for other
people's privacy.

Expected behavior includes:

- discussing ideas and code without attacking people;
- giving actionable feedback and accepting correction;
- respecting boundaries around private data and unpublished work;
- crediting other people's work and honoring licenses;
- avoiding harassment, discrimination, threats, sexualized conduct, and
  deliberate disruption.

## Scope

This policy applies to repository issues, pull requests, discussions, release
channels, and other spaces where someone represents the project.

## Enforcement

For ordinary disagreements, use the repository's moderation tools and contact
the maintainers through the repository owner's GitHub profile. Do not disclose
sensitive reports publicly.

Maintainers may edit or remove content, lock conversations, reject
contributions, or temporarily or permanently restrict participation when
behavior threatens contributors or the project.

Enforcement decisions should consider context, severity, repetition, and the
safety of affected people. Good-faith technical disagreement is not a conduct
violation.
