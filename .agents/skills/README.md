# Project-local skills

These skills are vendored for Vibe Roaster motion and launch-media work. Read
the task-specific `SKILL.md` before using one.

## HyperFrames

Source: `heygen-com/hyperframes`  
Installed from commit: `e2e61b0767b4b4dd282773eb50aa7ebaea98f0e5`

- `product-launch-video`: primary workflow for Vibe Roaster launch films.
- `hyperframes`: intent router for other video and motion requests.
- `hyperframes-core`: deterministic composition and timing contract.
- `hyperframes-animation`: motion recipes, transitions, and scene blueprints.
- `hyperframes-keyframes`: seek-safe keyframes and pixel verification.
- `hyperframes-creative`: visual direction and brand-to-frame translation.
- `hyperframes-cli`: preview, lint, snapshot, and render workflow.
- `media-use`: local media, audio, and asset ledger.
