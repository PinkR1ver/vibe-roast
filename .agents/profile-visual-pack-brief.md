## Purpose

This branch exists only to brief and hand off a visual asset task. It should stay small and free of product implementation noise.

The assigned person should design a Vibe Profile visual pack with internet-native humor, character, and taste. The most important suggested direction is:

- Make 16 small Vibe Profile characters, similar in spirit to MBTI / SBTI personality characters.
- Each character should represent a coding vibe or agentic working style.
- The characters should feel meme-aware, collectible, and useful in the product, not like corporate stock avatars.

## Branch Contents

- `.agents/profile-visual-pack-brief.md`: this branch brief.
- `.doodle/index.html`: a tiny visual prompt page showing one rough MBTI-like Vibe character.
- `task-assign.md`: direct assignment instructions.
- `assests/`: intentionally empty starting folder for the assignee to design their own asset structure.

## Constraints

- Do not modify app logic, data collection, dashboard code, build tooling, or package files in this branch.
- Do not treat the current doodle as final art. It is only a visual seed.
- Do not commit private session data, raw prompts, credentials, or personal secrets.
- The assignee may decide the final file structure inside `assests/`.

## Suggested Outcome

A strong first pass would include:

- A proposed taxonomy of 16 Vibe characters.
- Rough sketches or generated drafts for several characters.
- A planned folder and naming structure under `assests/`.
- Notes on visual tone, recurring motifs, and how the characters map to Vibe Profile types.
