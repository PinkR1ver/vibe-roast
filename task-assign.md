# Task Assignment: Vibe Profile Visual Pack

Assignee: `ShinjukuZhu`

## Task

Design the first Vibe Profile visual pack.

The suggested direction is to make 16 small character images, similar in spirit to MBTI / SBTI personality characters, but for vibe coding identities. The goal is not to copy MBTI visuals. The goal is to create a set of internet-native, funny, recognizable little Vibe characters that could become the face of this product.

## Creative Requirements

- Bring your own taste, memes, references, and visual judgment.
- Think of these as collectible profile characters, not generic user avatars.
- Each character should communicate a working style through pose, tool, expression, prop, or scene.
- The set should work in a dark dashboard and on social share cards.
- Avoid baking long English or Chinese text into reusable images.

## Suggested Character Set

You can change this taxonomy if you have a better one, but start by considering 16 Vibe Profile archetypes:

- Builder
- Debugger
- Architect
- Designer
- Researcher
- Automator
- Tester
- Publisher
- Refactorer
- Explainer
- Prompt Crafter
- Token Maxxer
- Workflow DJ
- Terminal Monk
- UI Polisher
- Chaos Shipper

## File Structure

The `assests/` folder is intentionally empty except for a placeholder so you can design the structure yourself.

Suggested options:

- `assests/characters/`
- `assests/banners/`
- `assests/share-cards/`
- `assests/badges/`
- `assests/source/`

Use whatever structure best supports the work.

## First Deliverable

Please commit:

- Your proposed `assests/` folder structure.
- A short note explaining the 16-character taxonomy.
- At least 3 rough character directions or drafts.
- Any source prompts, references, or generation notes that help future iteration.

## Non-Goals

- Do not change product code.
- Do not implement dashboard UI.
- Do not solve every banner/share-card need in the first pass.
- Do not treat `.doodle/index.html` as final visual direction.
