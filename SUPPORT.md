# Support

Use the appropriate channel:

- Bug or reproducible regression: open a Bug report.
- Feature proposal: open a Feature request.
- Security vulnerability: follow [SECURITY.md](SECURITY.md), never a public issue.
- General usage question: open a GitHub Discussion when enabled, otherwise use
  an issue with the `question` label.

Before asking for help:

- check the README and existing issues;
- use the latest published version;
- include your OS, Node.js version, command, and selected source adapters;
- replace private prompts, paths, and session data with synthetic examples.

Maintainers cannot debug private machine state without a minimal reproducible
example and cannot guarantee response times.
